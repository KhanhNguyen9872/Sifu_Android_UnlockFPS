A high-performance optimization modification for **Sifu Mobile (Android)**, unlocking high refresh rates for modern mobile displays with an integrated performance monitoring HUD.

---

## Features

- **High Refresh Rate Support**: Removes the hardcoded 60 FPS engine cap. Fully supports **90Hz, 120Hz, 144Hz, and 165Hz** displays.
- **Consistent Frame Pacing**: Resolves framerate throttle regressions during scene transitions and menus, maintaining smooth 120 FPS across gameplay and UI.
- **Smoothed Performance HUD**:
  - Displays real-time **FPS** and **Frame Latency (ms)** in-game.
  - **1.0-second refresh latch** to eliminate distracting per-frame jitter.

## Quick Start

1. Download the latest build from [**Releases**](../../releases).
2. Install the APK on your device.
3. Verify your device refresh rate is set to **120Hz** (or highest supported) in Android System Settings.
4. Launch the game and enjoy ultra-responsive martial arts combat.
